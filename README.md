# Quick Bay - Digital wallet
## Project over view
* **Quick pay is a java program which help you transfer money
## Admin Panel
*show statistics : show you every information you want to know like active or blocked transaction
*search user: let you search for a specific user
*view all users: let you see all information about all of users 
*update: permit you to update your info
*Transaction history: show you all transictions
*block \ unblock: manage account access and show you all blocked and unblocked acouts
*view user details : let you check information for a specific user
## User panel
*Transfer money: send or recieve money
*transaction history: show all transaction you did
*favourite management: let you add or remove or see favourites
*search recipient: let you search for someone to receive money
*profile management: view and update personal iformation
## Transfer rules
*you can't send money to yourself
*you should have a balance greater than money you want to send
*failed transactions don't change the balance
*the accounts of sender and recipient must be active
